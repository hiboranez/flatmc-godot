输入控制 :

1.键盘
W : 跳跃/向上飞（双击开启/关闭飞行模式）
A : 向左走（双击向左跑）
D : 向右走（双击向右跑）
S : 向下飞（飞行模式下）
F1 : 显示/隐藏GUI
F2 : 截图
F3 : 显示/隐藏坐标信息
Tab : 显示/隐藏在线玩家信息（需要开启服务器）
T : 开启/关闭聊天框
Esc : 暂停/关闭上一级UI
1至9 : 切换1至9号物品栏

2. 鼠标
左键 : 破坏方块
右键 : 放置方块
滚轮 : 切换物品栏
单击物品栏 : 切换物品栏

3.移动端
方向键：控制移动与跳跃
双击左方向键 : 向左跑
双击右方向键 : 向右跑
双击上方向键 : 开启/关闭飞行模式
短按 : 放置单个方块
长按 : 持续破坏方块
双击拖动 : 持续放置方块
滑动物品栏 : 切换物品栏
F1 : 显示/隐藏GUI
F2 : 截图
F3 : 显示/隐藏坐标信息
Tab : 显示/隐藏在线玩家信息（需要开启服务器）
右上角聊天按钮 : 开启/关闭聊天框
右上角暂停按钮 : 暂停/关闭上一级UI

现有指令 :

1./help 查看指令列表
2./tp <x坐标> <y坐标> : 传送至对应坐标

联机手册 :

1.局域网联机
(1) 在服务器设备上，单人模式下选择进入一个世界
(2) 暂停游戏，点击对局域网开放
(3) 在其他设备上，同一局域网的情况下，游戏会自动探测服务器，点击加入即可

2.服务器联机
(1) 添加服务器 : 输入正确的ip和端口
(2) 保存后会显示服务器连接信息
(3) 若服务器正确点击加入即可

Q&A :
1.移动端和主机端联机互通吗？
A : 互通的，只要服务器地址输入正确即可联机游玩
2.游戏存档文件夹在哪？
A : 一般情况下，windows系统中在C:/Users/用户名/AppData/Roaming/Godot中，安卓系统在Android/data/org.godotengine.godot中，世界存档在worlds文件夹下，若需存档转移请将存档放在该文件夹下
3.游戏中途退出会自动保存吗？
A : 一般情况下，如果是主机端会自动保存，但不排除强制退出的情况会丢失数据，最好从暂停菜单保存并退出。安卓端直接退出会丢失数据
4.无限世界存档会越玩越大吗？
A : 会，世界会以区块的形式加载存储，走过的区块越多存档越大
5. 我可以宣传本游戏吗？
A : 可以，但必须在宣传时注明作者名称和游戏官方下载方式，不允许私下贩卖传播
