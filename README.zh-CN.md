> FlatMC Godot Alpha 已停止开发和维护，FlatMC 已由 **FlatCraft** 取代。本仓库仅作为历史记录保留，不保证与 FlatCraft 兼容。

## 项目简介

FlatMC Godot Alpha 是功能最完整的 FlatMC 实现，支持 Windows、Android、单人世界、局域网和专用服务器联机、区块存档、生存与创造、合成、农业、实体、成就、资源包和多语言。

## v0.1.0 内容

- Windows 和 Android 操作。
- 基础方块和超平坦区块生成。
- 区块世界和玩家存档。
- 主菜单、单人、多人、设置和语言页面。
- 中英文、音乐、音效和调试信息。
- 聊天、LAN 发现、手动服务器和官方测试服务器。
- `/help` 和 `/tp` 命令。

## 已知限制

- 当前仓库是后期保存快照，不是还原后的 `v0.1.0` 源码树。
- 当前没有附带可验证的原始 `v0.1.0` 构建。
- 三个周更快照的详细记录尚未完全恢复。
- 历史存档和协议不兼容 FlatCraft。

## 项目状态

**已归档 / 已被取代**

项目已停止开发，FlatCraft 是 FlatMC 的后继项目。
