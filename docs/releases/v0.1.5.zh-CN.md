### 生存与世界

- 加入生存模式、受伤提示、死亡动画和登录、离线、传送动画。
- 加入火把、光线传播和日光。
- 加入基于噪声的自然地形和平原生物群落。
- 调整 `/gamemode` 命令。

### 修复

- 修复碰撞、方块同时操作、区块同步和玩家位置回弹问题。
- 提升渲染范围并修正区块名称。
- 停止 Windows ARM64 支持。

### 文档

- 添加以英文为默认语言的 README 文档。
- 添加简体中文 README，并提供双向语言导航。
- 记录原始版本号与规范化版本号、已知功能、限制和归档状态。
- 为本次 Release 添加独立且内容完整的简体中文更新日志。
- 记录此历史标签实际采用的最终归档源码快照。
- 记录 FlatMC 已由 FlatCraft 取代。
